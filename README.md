# WELIH Tools

Terminal-based offensive security toolkit for Linux environments.

## Quick Installation

```bash
git clone https://github.com/realwelih/welih-tools.git

cd welih-tools

python3 python.py
```

## Install Requirements

```bash
sudo apt update

sudo apt install -y \
python3 \
python3-pip \
figlet \
toilet \
nmap \
whois \
hydra \
medusa \
gobuster \
sqlmap \
commix \
steghide \
exiftool
```

## Included Tools

- Nmap
- Whois
- SQLMap
- Hydra
- Medusa
- Gobuster
- Sherlock
- Commix
- Steghide
- Hash utilities
- WAF detection
- ExifTool integration
